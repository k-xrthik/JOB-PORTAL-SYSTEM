# HireMeNow — Job Portal Backend

Backend service and RESTful API for the **HireMeNow** job portal system, built with **ASP.NET Core Web API**, **Entity Framework Core**, and **SQL Server** to support role-based workflows for job seekers and job providers.

## Key Backend Features
- **Role-Based Access & Security:** Endpoints and authorization flows secured with **JWT** authentication for distinct user roles (job seekers and job providers).
- **Profile & Domain Workflows:** Backend business logic and API endpoints for managing candidate profiles, company profiles, and job portal workflows.
- **Data Access & Persistence:** Relational database modeling and data access powered by **Entity Framework Core** and **SQL Server**.
- **RESTful API Integration:** Structured API endpoints designed to integrate cleanly with frontend client applications.

## Tech Stack
- **Backend:** C#, ASP.NET Core Web API, Entity Framework Core
- **Database:** Microsoft SQL Server
- **Security:** JWT Authentication & Authorization
